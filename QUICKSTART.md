# Clearbook Quick Start Guide

Get up and running with Clearbook in 2 minutes! ✨

## Install (30 seconds)

1. Open Firefox
2. Type `about:debugging` in the address bar
3. Click "This Firefox" → "Load Temporary Add-on"
4. Select `manifest.json` from the clearbook folder
5. Done! The Clearbook icon appears in your toolbar

## First Use (1 minute)

1. **Click the Clearbook icon** in your toolbar
2. All features are **enabled by default** - perfect for most users
3. Click **"🔄 Refresh Page"** to apply changes to current tab
4. Visit **facebook.com** and enjoy your clean feed!

## Quick Settings

Click the Clearbook icon to toggle:

| Setting | What it does |
|---------|--------------|
| 🚫 Hide Ads | Removes all advertisements and sponsored posts |
| 🎯 Hide Suggested Content | Removes "Suggested for you" posts |
| 🎬 Hide Reels | Removes short video content |
| 🛒 Hide Marketplace | Removes marketplace recommendations |
| 🤖 Hide AI Content | Filters AI-generated posts |
| 👥 Friends Only Feed | Shows only posts from friends (strict) |
| ⏰ Chronological Feed | Newest posts first |

## Themes

Choose your style:

- **Classic** - Original Facebook look
- **Minimal** ⭐ *Recommended* - Clean and simple
- **Dark** - Easy on the eyes
- **Hacker News** - Orange accent, ultra-minimal

Change theme: Click icon → Select theme → Done!

## Advanced Settings

Click **"⚙️ All Settings"** for:

- 🔍 **Facebook-specific filters** - Fine-tune what's hidden
- 🚫 **Keyword blacklist** - Hide posts with specific words
- 📤 **Export/Import** - Backup or share your settings
- 🔄 **Reset** - Return to default settings

## Keyboard Shortcuts

Set custom shortcuts:
1. `about:addons` → ⚙️ → "Manage Extension Shortcuts"
2. Assign a key combo to Clearbook
3. Press it anytime to open the popup

## Tips & Tricks

### Hiding Specific Content

Add keywords to blacklist:
1. Open "⚙️ All Settings"
2. Scroll to "Keyword Blacklist"
3. Type keyword → Click "Add"
4. Posts with that keyword are hidden

Examples:
- "crypto" - Hide crypto posts
- "political" - Hide political content
- "election" - Hide election posts

### Maximum Minimalism

For the cleanest experience:
1. Enable all filters ✅
2. Choose "Minimal" or "Hacker News" theme
3. Enable "Friends Only Feed"
4. Add noisy keywords to blacklist

### Temporary Disable

Want to see everything temporarily?
1. Click Clearbook icon
2. Uncheck "Hide Ads" and other filters
3. Refresh page
4. Re-enable when done

## Troubleshooting

### Not working?
- **Refresh the page** (F5 or 🔄 button in popup)
- **Reload extension** (`about:debugging` → Reload)

### Still seeing ads?
- Make sure toggles are ON (✓)
- Facebook changes their code often - update Clearbook
- Report missed ads on GitHub

### Theme not applying?
- Select theme in popup
- Refresh the page
- Clear browser cache if needed
